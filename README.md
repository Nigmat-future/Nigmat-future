# Hi, I'm Nigmat

I build biomedical AI systems, agentic research workflows, and developer tools for turning messy scientific questions into reproducible work.

My work sits at the intersection of:
- bioinformatics and translational research
- agent systems and research automation
- clinical and scientific interfaces
- tooling for multimodal, data-heavy workflows

## What I'm building

### Biomedical AI and research systems
- [bioagent](https://github.com/Nigmat-future/bioagent)
  Autonomous multi-agent system for end-to-end bioinformatics research.
- [biomedical-codex-skills](https://github.com/Nigmat-future/biomedical-codex-skills)
  A publishable multi-skill repository for biomedical AI coding and agent workflows.
- [publishable-research-orchestrator](https://github.com/Nigmat-future/publishable-research-orchestrator)
  Codex skill for multi-agent research discovery, publishability scoring, and execution planning.
- [biomedical-skill-suite](https://github.com/Nigmat-future/biomedical-skill-suite)
  A layered biomedical skill library for study design, public-cohort planning, omics workflows, validation, and manuscript-oriented research packaging.

## Current themes

Right now I am especially interested in:
- agentic biomedical research systems
- publishable study design for public and translational datasets
- single-cell, spatial, imaging, and multi-omics workflows
- clinical AI interfaces that are useful under real-world constraints
- developer tooling that reduces friction between research ideas and working systems

## Working style

I like building systems that are:
- modular instead of monolithic
- research-aware instead of generic
- execution-oriented instead of presentation-heavy
- useful for real workflows, not only demos
